# M5: the skinned app

*2026-10-22 · agent: shell · scratch path `.build-shell5` · bundle `build-shell5/sudamp.app` (the owner's
`build/sudamp.app` was never touched) · macOS 27.0.1, M5 Pro, one 1x display, **screen locked throughout**
(`CGSSessionScreenIsLocked = 1`), Command Line Tools only, Swift 6.4.*

**Verdict: GO for PLAN M5.** The CPU gate passes with a thin margin (playing 2.69–2.90 %, mean 2.76 %, against
≤ 3 %; paused 0.36–0.39 % against ≤ 0.5 %). The skinned
windows are the default front end; `--plain` keeps M2's window. Open sudamp: Main and Playlist open docked in sudamp
Dark, the genre menu drops open under the marquee by itself, Deep House is chosen in it and music plays. Every
terminal gate below was run on the final release bundle with direct launches, `--mute` and throwaway profiles
(argument/instance-socket forwarding instead of LaunchServices). YouTube budget: **0 of 10** resolves used (the picks
were radio, SoundCloud and Mixcloud); no bot check, `LOGIN_REQUIRED` or 429.

## Findings

- **`NSMenu.popUp` must never run inside a main-queue job.** Its tracking loop then can't drain the main queue, so
  main-actor work (hover pre-resolve, automation, the watchdog) stalls until the menu closes (M2's quit finding, again).
  Every pop-up — clicks included — is started from a zero-delay `perform(…inModes: [.common])`; a cancelled menu's
  loop unwinds on the next turn, so a new pop-up waits for it (`trackingDepth`).
- **Menus open and track on a locked screen** for an accessory (automation) app, and items chosen with
  `performActionForItem(at:)` after `cancelTracking` behave as clicks. Automation closes any menu it opened within
  15 s and only reproduces the first-launch auto-open when the script waits for it (`waitForMenu auto`), so no script
  leaves a menu holding the owner's keyboard.
- **CPU went into small things.** Before: 3.1 % playing, 0.96 % paused. A scrolling title redrew at 30 Hz (now a
  one-shot timer at each 220 ms step, merged into the visualiser's frames while those run); the marquee re-ran
  Unicode decomposition per character on every step (`deburr`: an ASCII fast path) and copied the whole 128 KB frame
  (drawn on its 154×6 strip now); every base render hashed itself (skipped in the UI); the time's once-a-second change
  re-uploaded whole windows (only the changed rectangle now, as a patch layer); Main mapped the station list on every
  refresh (only the Playlist does now); a paused title kept scrolling (it now stands still while paused; the time
  blinks — a deliberate departure from Winamp, which scrolls on, for the 0.5 % paused budget); `state.json` was
  re-encoded every second while playing (position-only changes now at most every 5 s; everything else within
  0.25 s). What is left is mostly the 30 Hz display link and Core Animation commits.
- **Visualiser under `--mute`:** the render bridge writes its ring before zeroing the output, so the visualiser shows
  real audio in muted runs.
- **Cold SoundCloud/Mixcloud picks were slow today** (resolve 2.2–2.8 s vs M2's ~1 s); with radio first picks the
  north star sits around 1 s. M7's probe could prefer radio for the first pick of a session.

## Not done, deviations, open

- **Manual (owner):** `docs/feedback/M5.md` — real clicks and drags, Spaces, two displays, sleep/wake, Retina 2x
  crispness, shaped-skin click-through (S1's pending check; region.txt stays on, behind View ▸ Shaped Windows).
  Nothing here could be seen: the screen was locked and the only display is 1x.
- **CPU is measured with `--ignore-occlusion`** on the locked screen (otherwise the occluded windows stop animating
  and the number means nothing); an unlocked visible run is in the owner's checklist.
- **Automation shows menus on screen** (they are real pop-ups at the anchors, for ~10–50 ms each); scripts never
  activate the app or show windows unless they ask (`showWindows`).
- **Right-click opens the context menu at the pointer** with `Genre ▸` first (DESIGN §3), not the bare genre menu
  under the marquee; the dump checks that its `Genre ▸` is the same menu.
- **Title format** follows DESIGN §3 (`[DEEP HOUSE] CREATOR - TITLE`), not `GENRE ▸ …`: `▸` isn't in Winamp's
  text.bmp font and would switch the whole marquee to the system-font overlay.
- **One-off streams** from Open Stream URL show `SOURCE - <ref>` until M7 can carry yt-dlp's title into the marquee.
- **⌘W** does nothing on the borderless skinned windows (no close button for AppKit to press); the skin's close
  buttons and Window ▸ Close… on the plain window work.
- **The EQ window opens below the Playlist** on a first launch (SkinUI keeps closed windows in the stack in the order
  they were placed); Regroup Windows puts it back between Main and the Playlist.
- `docs/measurements.md` is not this agent's file: the numbers above are requested as an append.

## Reproduce

```
make verify-binary CONFIG=release APP=build-shell5/sudamp.app
A=build-shell5/sudamp.app/Contents/MacOS/sudamp
T=$(mktemp -d); .build/release/sudamp-dev engine install --profile "$T"     # once (or a debug sudamp-dev)
fresh() { P=$(mktemp -d); cp -Rc "$T/engines" "$P/"; echo "$P"; }
# north star (3 runs, median ttfaMs)
for i in 1 2 3; do $A --mute --profile "$(fresh)" --automation Fixtures/automation/northstar.json --json \
  | jq -e '.menuAutoOpened==true and .automation.menuSelections[0].genre=="deep-house" and .state=="playing"' >/dev/null \
  && echo ok; done
# snapshots
$A --snapshot "$(mktemp -d)" --states Fixtures/states/app/*.json | jq -e '.ok and .compared'
# menus
$A --mute --profile "$(fresh)" --automation Fixtures/automation/menus.json --json | jq -e '
  (.automation.menus[0] | (.entryPoints|sort) == ["contextMenu","dock","marquee","menuBar","options","statusItem"]
     and .sameGenreMenu and ([.genreMenus[]]|unique|length) == 1)
  and ([.automation.openedMenus[].genreMenu]|unique|length) == 1'
# eqf round trip
$A --mute --profile "$(fresh)" --automation Fixtures/automation/eqf-roundtrip.json --json | jq -e '.automation.dumps as $d
  | $d[2].ui.equalizer.bands == $d[0].ui.equalizer.bands and ($d[1].ui.equalizer.bands|all(.==0))'
# skins by forwarding (no LaunchServices)
P=$(fresh); $A --mute --profile "$P" & sleep 3
$A --profile "$P" Fixtures/skins/AndAmp-Dark.wsz; jq -r .skin.id "$P/debug/state.json"        # andamp-dark
sudamp-dev skin-fuzz --make-bomb /tmp/bomb.wsz; $A --profile "$P" /tmp/bomb.wsz; sleep 1
jq -e '.lastError.kind=="skinRejected" and .skin.id=="andamp-dark"' "$P/debug/state.json"
$A --profile "$P" 'sudamp://quit'
/usr/libexec/PlistBuddy -c 'Print :UTExportedTypeDeclarations:0:UTTypeTagSpecification:public.filename-extension:0' \
  build-shell5/sudamp.app/Contents/Info.plist                                                      # wsz
```
