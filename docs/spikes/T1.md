# Spike T1: Toolchain (PLAN M0)

**Verdict: GO** (2026-10-22, macOS 27.0.1, M5 Pro, Command Line Tools only, Swift 6.4)

| Check | Result |
|---|---|
| `make build` from clean | Builds all 13 library/executable targets with MPVKit 1.0.0 in about 18 s. The only warnings are CLT linker search paths, which are allowlisted in `Support/warnings-allowlist.txt` |
| `make test` twice | Both runs pass, including the incremental one. Swift Testing works through the `PLUGINS` path derived from `xcrun -f swift` |
| `make app` | Builds `build/sudamp.app`: `MacOS/sudamp` (41 MB debug, static libmpv), `Helpers/qjs` (QuickJS-NG v0.17.0, sha256-pinned), `Resources/sudamp_Shell.bundle`, `AppIcon.icns`. The app is ad-hoc signed inside-out and `codesign --verify --strict` passes |
| `sudamp --selftest --json \| jq -e '.resources.ok'` | `true`; `Bundle.module` resolves `Contents/Resources/sudamp_Shell.bundle` |
| Icon | `scripts/make-icon.sh` rasterises `assets/icon.svg` with `sips` into a 10-size `Support/AppIcon.iconset`, then runs `iconutil -c icns` |
| Info.plist | `plutil -lint` passes. `LSMinimumSystemVersion` is `15.0` and `CFBundleURLSchemes` is `sudamp` |
| `scripts/count-escapes.sh` | Exits 1 on a planted unjustified `@unchecked` and 0 once it has a `// SAFETY:` line; the repo has 0 escapes |
| `make verify-binary` | `_audio_out_pcm` resolves to `SudampAO.o` (the swiftbuild backend merges the C target into one object), the binary contains no ao_pcm file writer, it links only system libraries, and the signature is valid |

**Notes**

- **Merged object name.** Under the swiftbuild backend the linker map names the merged `SudampAO.o`, not `sudamp_ao.o`. `verify-binary.sh` accepts either, and DESIGN §5.3 is updated to match.
- **Vendored-header warnings.** The mpv headers emit `-Wshorten-64-to-32`. `sudamp_ao.c` suppresses warnings only around those third-party includes.
- **Pipes under pipefail.** `grep -q` after `strings` caused a SIGPIPE false failure under `pipefail`. Scripts read the whole stream with `grep ... >/dev/null` instead.
- **Locale.** awk needs `LC_ALL=C` to read the linker map.
