# M5 try-out: the skinned player

*For the owner. About 10–15 minutes. Tick or write next to each line and leave the file in place.* This is PLAN M5's
manual checklist (drag and dock, Spaces, displays, sleep/wake, shaped-skin click-through) plus the new controls.
Agents could not do these: the dev machine's screen was locked and has one 1x display.

## Before you start

```
cd ~/.t3/projects/sudamp
rm -f /tmp/sudamp-force-mute          # agents' guard: while this file exists, debug builds play silently
make app CONFIG=release               # rebuilds build/sudamp.app (release: what the CPU numbers are for)
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f build/sudamp.app
open build/sudamp.app
```

- A first-time look: quit sudamp, then
  `rm -rf ~/Library/Application\ Support/sudamp ~/Library/Caches/sudamp ~/Library/Logs/sudamp` (or try a throwaway
  profile: `open build/sudamp.app --args --profile /tmp/sudamp-try`).
- The M2 plain window is still there: `open build/sudamp.app --args --plain` (or
  `build/sudamp.app/Contents/MacOS/sudamp --plain`).

## 3. Controls (3 min)

- [ ] Transport buttons and keys `Z` previous, `X` play, `C` pause (again to resume), `V` stop, `B` next.
- [ ] Drag the position bar on a mix (YouTube/SoundCloud/Mixcloud): it seeks; on radio or a live stream it doesn't move.
- [ ] Volume and balance sliders; the mouse wheel over Main changes the volume.
- [ ] **Shuffle** = "Surprise-genre mode": Next (and the end of a mix) jumps to a random genre. **Repeat** = a mix that
      ends plays again. Do these meanings feel right for a radio player? ______
- [ ] Click the time: elapsed ↔ remaining. Click the visualiser: spectrum → oscilloscope → off.
- [ ] `⌘F` favourites the current stream (★ Favourites in the genre menu then plays your favourites at random).
- [ ] `⌘⌫` "Never play this": it skips at once and never comes back; `⌘Z` (Edit ▸ Undo) lets it back in;
      Controls ▸ Recently Banned ▸ does too.
- [ ] `⌥⌘C` Copy Link: paste it somewhere: `Creator - Title https://…&t=754s` (YouTube) or `#t=12:34` (SoundCloud).
- [ ] Eject button or `⌘L`: paste a YouTube/SoundCloud/Mixcloud link or a radio URL; it plays. A nonsense link
      explains why it can't.
- [ ] Double-click a Playlist row: that stream plays.

## 4. Equalizer (2 min)

- [ ] The EQ button on Main opens the Equalizer docked to the stack; sliders, preamp and ON change the sound.
- [ ] PRESETS: the 17 presets; **Save .eqf…** then **Load .eqf…** brings the same curve back. Winamp `.eqf` files load.
- [ ] Quit and relaunch: EQ, volume, skin, scale and window positions come back.
