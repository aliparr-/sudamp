# M2 try-out: the plain app

*For the owner. About 15 minutes. Fill in the blanks (or just write next to them) and leave the file in place; catalog
notes feed M7.* This is the walking skeleton: a plain native window, no skins yet (those arrive in M5).

## Before you start

```
cd ~/.t3/projects/sudamp
rm -f /tmp/sudamp-force-mute     # agents' test guard: while this file exists, debug builds play silently
make app                         # builds build/sudamp.app (about a minute the first time)
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f build/sudamp.app
open build/sudamp.app
```

- To start again as a first-time user: quit sudamp, then `rm -rf ~/Library/Application\ Support/sudamp ~/Library/Caches/sudamp ~/Library/Logs/sudamp`.
- To try a throwaway profile instead: `open build/sudamp.app --args --profile /tmp/sudamp-try`.
- If something goes wrong, `~/Library/Logs/sudamp/metrics.jsonl` and `~/Library/Application Support/sudamp/debug/state.json`
  say what happened; `log show --last 10m --info --predicate 'subsystem == "app.sudamp"'` has the details.

## 4. Controls and the rest of the Mac

- [ ] Play/Pause button, `Space`, and Controls menu `X` play / `C` pause / `V` stop / `Z` previous / `B` next.
- [ ] Previous goes back to what played before.
- [ ] Volume slider; `⌘↑` / `⌘↓`. The volume is remembered next launch.
- [ ] Menu bar **Genre** menu: `⌘1`…`⌘9` pick genres, `⌘0` is Surprise Me; the current genre is ticked.
- [ ] The ♪ menu-bar icon: what's playing, genres, Play/Pause, Next, Quit.
- [ ] Right-click the Dock icon: genres, Play/Pause, Next.
- [ ] Keyboard media keys (or AirPods / Control Center) play, pause and skip; Control Center shows the stream with the
      genre, and live streams show as live.
- [ ] In Terminal: `open 'sudamp://genre/techno'`, `open sudamp://next`, `open sudamp://toggle`, `open sudamp://quit`.
- [ ] Launching sudamp again while it runs just brings the window forward (no second copy).

## 5. Quitting and coming back

- [ ] Quit (`⌘Q`, the window's close button, or `open sudamp://quit`) while something plays. Relaunch: the same genre
      starts by itself with a gentle 1.5 s fade-in; a long mix carries on where it was (if under 6 h ago).
- [ ] Pause, then quit. Relaunch: nothing plays by itself; the window offers `Press Play for <genre>`.
