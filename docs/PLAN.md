# sudamp: milestone plan (v1)

*Companion to `docs/DESIGN.md` · 2026-10-22 · Status: Proposed — awaiting owner review of DESIGN §13 decisions*

## Conventions

- **Sizes** are unmeasured estimates of agent effort: **S** ≤ 2 agent-days, **M** 3–7, **L** 8–15.
- **Where criteria run.** From a terminal on the CLT-only dev machine (macOS 27.0.1, arm64), checked with exit codes, `/usr/bin/jq`, `log show`, `/usr/bin/time -l` and `metrics.jsonl`. **(live)** checks need the network and `SUDAMP_LIVE=1`; **(manual)** ones need a human and are recorded in `docs/spikes/` or `docs/feedback/`.
- **Time and faults.** Checks that span hours use `SUDAMP_CLOCK_OFFSET=<s>` (debug builds, read by Core's Clock) or a fake Clock in Swift Testing. `SUDAMP_FAULT=<class:kind>` grows milestone by milestone; each milestone lists the faults it adds.
- **Definition of done, every milestone:** `make build test verify-binary` is green (`make build` runs `scripts/check-warnings.sh`; `make test` runs `scripts/count-escapes.sh`); new borrowed code is in `PROVENANCE.md`; measured numbers are appended to `docs/measurements.md`.
- **Isolated profiles.** `SUDAMP_HOME=<dir>` or `--profile <dir>` sends Application Support, Caches and Logs to a scratch directory; every app-level test uses a fresh `mktemp -d`. Paths inside a profile follow DESIGN §10: `$P/session.json`, `$P/debug/state.json`, `$P/Logs/metrics.jsonl`.
- **North-star rule.** "Open → pick genre → music" works headless at M1 and in the plain app at M2, before any skin work is merged into the app.
- **Inputs.** Spike code to port is in `spikes/engine-pull-ao/` and `spikes/skins-tools/`; evidence is in `docs/research/`.

## Dependency graph

```
M0 ─┬─► M4 SkinKit & sudamp Dark ─────────────────────────────┐
    └─► M1 Thin slice ─┬─► M2 Walking skeleton ───────────────┤
                       ├─► M3 Audio & resolver completeness ──┴─► M5 Skinned app ──┐
                       └─► M6 Resilience & engine updates ─────────────────────────┴─► M7 Remote feed ─► M8 Release ─► M9 1.0
```

M2, M3 and M6 need only M1 and run in parallel; M4 needs only M0, so a second agent or branch can start it at once. M5 needs M2, M3 and M4; M7 needs M5 and M6; M8 also needs a Developer ID.

**Owner actions** (DESIGN §13): approve genres (M1, M7, M9); create a GitHub remote (for the `macos-15` CI job and M7's Pages); enrol for a Developer ID and register the domain before M8 (the ID earlier only for the optional N1 probe); get the EU legal opinion (M9).

## M0: Foundations and spikes (M)

**Goal.** Prove the risky pieces inside a real `.app` on this machine before writing features. Each spike has a terminal-verifiable GO criterion and a written NO-GO plan.

**Deliverables**
- **Package skeleton:** every DESIGN §4 target compiles, mostly empty; MPVKit pinned `exact: "1.0.0"`; no Homebrew packages (DESIGN §9).
- **Makefile:** `build`, `test` (with `PLUGINS` derived from `xcrun -f swift`), `app`, `app-hardened`, `verify-binary`, `run`.

- **`sudamp-dev`:** `bench-transport`, `stress-lifecycle`, `devswitch`, `engine install`, `resolve`, `play-url`.
- **Fixture:** `.build/fixtures/ramp60.wav` (44.1 kHz), generated by `sudamp-dev gen-ramp` from the spike's position-ramp generator; never committed.

## M1: Thin slice, headless (M)

**Goal.** The shortest path to the north star: `sudamp-dev play --genre deep-house` plays real feed streams end to end (feed → picker → resolver → mpv → pull AO → AVAudioEngine).

**Deliverables**
- **Core:** paths, `SUDAMP_HOME`, logging, `metrics.jsonl`, `Subprocess` (posix_spawn into a process group), Clock with `SUDAMP_CLOCK_OFFSET`, and the instance lock (`flock` on `<profile>/instance.lock`, also taken by `sudamp-dev play`).
- **Bundled feed:** `catalog/feed.json` (DESIGN §7) with **3 genres**, each with ≥ 8 streams, ≥ 2 radio stations and ≥ 2 source types, including Mixcloud items. No SomaFM stations until SomaFM grants permission; the request is emailed in M1. Its engine `pin` (SHA-256 copied by hand from upstream's `SHA2-256SUMS`) and `block` are honoured from here on. Lenient decoding, the canonicaliser and allowlist (including `UC…` → `/channel/<id>/live` and Mixcloud `user/slug`), the radio DNS check, and strict validation of engine strings.
- **Picker:** a basic shuffle-bag with deferral and fast-start; the pure `SessionMachine`; `session.json` and `library.json`.
- **Resolver:** EngineStore first install (pin/block, SHA-256, `tree.json`, launch re-hash); ResolverService (serial, pre-emptible, private HOME/XDG, one cache dir); JS-less tier-1 YouTube VOD and `/live`, SoundCloud, Mixcloud and radio; `available_at`; expiry cache; prefetch depth 1; the YouTube token bucket; a basic stderr classifier (skip on failure, Mixcloud `restrictedReason` included) with fixtures.
- **MPV:** the wrapper (async commands, event thread, observed properties, guards).
- **Audio:** the graph (source node → EQ at flat → mixer → output), the volume curve, host pause with 5 ms ramps and the 1.5 s launch fade (per-channel gains in the C render bridge), the TTFA stamp.
- **`sudamp-dev play | ttfa`** (`play` accepts `--source <s>` to restrict picks, `--next-every <s>` and `--no-engine`).

**Acceptance criteria**
- `make test` is green, including:
  - canonicaliser accept/reject tables with hostile inputs (`file://`, IP literals, userinfo, `localhost`, private DNS answers) and Mixcloud refs;
  - a feed test that runs the Catalog validator on `catalog/feed.json`, including the coverage rule for the 3 genres;
  - bag tests: no repeat within a bag, χ² p > 0.01 over 10k seeded draws, and deferral that doesn't consume items;
  - every SessionMachine transition; argv goldens per source; every stderr fixture class;
  - EngineStore: with a fixture feed whose `block` lists the newest release, a first install picks `pin`;
  - the token bucket under a fake Clock: ≤ 123 YouTube resolves in the first simulated hour from a full bucket and ≤ 120 in each later hour; hover is refused below 2 tokens; with 0 tokens a YouTube item is deferred, not consumed;
  - `MPVTests` pulling `sudamp_ao_read` on the test thread for seek, pause, loadfile and init count.
- **(live)** `swift run sudamp-dev play --genre deep-house --seconds 120 --next-every 20 --json` exits 0 with ≥ 5 streams started, per-stream TTFA in `metrics.jsonl`, TTFA ≤ 1.0 s p50 for prefetched picks and 0 unhandled errors. Picks falling back to SoundCloud, Mixcloud or radio under YouTube throttling are expected.
- **(live)** `swift run sudamp-dev ttfa --source radio,radio-http,soundcloud,mixcloud,youtube,youtube-live -n 5 --json` writes end-to-end TTFA per source to `docs/measurements.md`, and each source's p50 meets its DESIGN §2 row (`radio-http` uses the Radio row, `youtube-live` the Cold YouTube row).
- **(live)** With `--no-engine`, every pick is radio and TTFA is ≤ 2.0 s.
- A second `sudamp-dev play` on the same profile exits non-zero with `profile in use`.
- `swift run sudamp-dev stress-lifecycle 100` and `bench-transport` stay within M0 thresholds.

**Dependencies:** M0 (T1, E1, R1 GO).

## M2: Walking skeleton app (S)

**Goal.** The owner can open the app, pick "Deep House" from a plain dropdown and hear music. Catalog quality and latency feedback start here, while skins are built.

**Deliverables**
- **Shell composition root** and `PlainWindow`: a standard AppKit window with an NSPopUpButton (every genre plus Surprise Me), Play/Pause, Next, Previous, a title label and a status line (engine download %, source, TTFA).
- **First launch:** the EngineStore download in the background with radio-first picks; it resumes with HTTP Range on the `.partial` file, checks for ~180 MB free, and shows `ENGINE DOWNLOAD FAILED - RADIO ONLY` with retry when github.com is unreachable.
- **Returning launch:** auto-resume with a 1.5 s fade.
- **Shell basics:** a minimal status-item menu; the `sudamp://genre/<id>|toggle|next|previous|quit` URL scheme (`CFBundleURLTypes`); Now Playing with media keys.
- **Single instance:** a second launch forwards its URL or arguments over `<profile>/instance.sock` and exits 0.
- **Quit path:** ⌘Q, `sudamp://quit` and SIGTERM all flush `session.json` before exit (DESIGN §4).
- **Agent hooks:** `--automation <script.json>` (select menu items, press controls, wait for states, dump state); debug `state.json`; `sudamp-dev wait --profile <P> --state <s> --timeout <s>` (polls `<P>/debug/state.json`).
- **Faults:** `SUDAMP_FAULT=engine:unreachable|engine:abort-at=<pct>|disk:full`.
- **Owner notes:** `docs/feedback/M2.md`, a try-out checklist (genres, stream quality, start latency, wording).

**Acceptance criteria**
- **(live)** Fresh profile, engine not installed:

  ```
  P=$(mktemp -d)
  build/sudamp.app/Contents/MacOS/sudamp --plain --mute --profile "$P" \
    --automation Fixtures/automation/northstar-plain.json --json \
    | jq -e '.state=="playing" and .genre=="deep-house" and .source=="radio" and .ttfaMs<=2000'
  ```

- **(live)** After `sudamp-dev engine install --profile "$P"`, the same script with `--skips 5` gives at least 1 YouTube, SoundCloud or Mixcloud start, and the p90 over the ≥ 5 starts is ≤ 3500 ms.
- **(live)** Download robustness, each on a fresh profile: `SUDAMP_FAULT=engine:unreachable` → radio plays and `.engine.download == "unreachable"`; `engine:abort-at=50`, then a relaunch → the log shows a resumed `Range` request and the install completes; `disk:full` → no download starts and `.engine.download == "noSpace"`.
- **(live)** URL scheme and single instance:

  ```
  LSREG=/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister
  $LSREG -f build/sudamp.app
  open -a "$PWD/build/sudamp.app" --args --plain --mute --profile "$P"
  open -a "$PWD/build/sudamp.app" 'sudamp://genre/deep-house'
  sudamp-dev wait --profile "$P" --state playing --timeout 5
  jq -e '.nowPlaying.playbackState=="playing"' "$P/debug/state.json"
  build/sudamp.app/Contents/MacOS/sudamp --profile "$P" 'sudamp://next'   # second launch: forwards, exits 0
  [ $(pgrep -x sudamp | wc -l) -eq 1 ]
  ```

  `.stream.id` changes within 3 s of the forwarded `sudamp://next`.
- **(live)** `open -a "$PWD/build/sudamp.app" 'sudamp://quit'`, and separately `kill -TERM $(pgrep -x sudamp)`, each exit within 2 s with `session.json` flushed; a relaunch shows `resumed == true` and the same genre within 2 s.
- `plutil -extract CFBundleURLTypes.0.CFBundleURLSchemes.0 raw build/sudamp.app/Contents/Info.plist` prints `sudamp`.
- **(manual)** The owner has tried the build; feedback is in `docs/feedback/M2.md`, and catalog changes feed M7. Not a gate for M3–M6.

**Dependencies:** M1.

## M3: Audio and resolver completeness (M)

**Goal.** The headless engine reaches v1 behaviour: EQ, balance, visualiser data, device changes, the QuickJS tier, live pause and proxies.

**Deliverables**
- **EQ:** 10 bands + preamp; MacAmp's 17 presets and `.eqf` codec with tests; the shelf A/B on bands 0 and 9 and the AUPeakLimiter evaluation (CPU, latency, transparency), decision recorded.
- **`sudamp-dev eq-selftest`** on an AVAudioEngine in offline manual rendering, or a muted live engine if AVAudioSourceNode doesn't render offline.
- **Render bridge:** C balance (ramps and the launch fade landed in M1).
- **Visualiser data:** the 8192-frame SPSC ring (MacAmp's algorithm and 16 tests, in C11 atomics) and the vDSP analyser.
- **Device changes:** MacAmp's observer (150 ms debounce), rewiring, and an engine rebuild after 3 failed starts, on E2's mechanism.
- **Resolver:** QuickJS-NG tier 2 (`visionos,tv_samsung`) with step-up and the 24 h local adaptation; system proxy pass-through (`CFNetworkCopySystemProxySettings` → yt-dlp `--proxy`, mpv `http-proxy`).
- **Live and radio pause:** a pause over 30 s reloads at the live edge on resume; the audio engine stops after 30 s paused or idle.
- **Tools and faults:** `sudamp-dev soak`; `sudamp-dev proxy` (a minimal logging CONNECT proxy); a debug-only `SUDAMP_PROXY=<url>` override; `SUDAMP_FAULT=youtube:jsless-fail`.

**Acceptance criteria**
- `swift run sudamp-dev eq-selftest --json` reports its mode (`offline` or `liveMuted`) and:
  - each of the 10 bands at +12 dB reads 12.00 ± 0.1 dB at its centre frequency (± 0.25 dB for ≥ 12 kHz);
  - preamp +6 reads 6.00 ± 0.1, and flat reads 0.00 ± 0.05;
  - balance fully left puts the right channel ≤ −60 dB;
  - EQ gains persist across `loadfile` and seek.
- `make test`: `.eqf` export/import gives equal gains; the ring-buffer tests pass; a synthetic 1 kHz sine peaks in the right bar; system-proxy fixture dictionaries map to the expected yt-dlp argv and mpv options (PAC-only or SOCKS-only to none).
- `sudamp-dev devswitch --cycles 20 --json` against the full Audio module: 0 crashes and audio within 500 ms of each switch.
- **(live)** `SUDAMP_FAULT=youtube:jsless-fail sudamp-dev play --genre deep-house --source youtube --next-every 30 --prefetch=false --seconds 65 --json` (≥ 3 YouTube picks in `metrics.jsonl`; prefetch off because a stepped-up pick spends two tokens from the shared bucket): YouTube picks resolve through tier 2 in ≤ 5 s; with `SUDAMP_CLOCK_OFFSET` under 24 h, later picks still start at tier 2, and beyond 24 h at tier 1.
- **(live)** A radio stream paused 45 s logs `liveReload` in `metrics.jsonl` on resume and is audible within 2 s; a 10 s pause resumes without a reload.
- **(live)** With `sudamp-dev proxy --port 8899` and `SUDAMP_PROXY=http://127.0.0.1:8899`, a YouTube resolve and an HTTPS radio load both appear in the proxy's log. This settles DESIGN §6.2's [unverified] HTTPS-tunnelling question.
- **(live)** `swift run sudamp-dev soak --minutes 30 --genre deep-house`: 0 crashes, RSS drift < 10 MB and 0 short reads outside device switches.

**Dependencies:** M1. Runs in parallel with M2, M4 and M6.

## M4: SkinKit and sudamp Dark (L)

**Goal.** A pure, fully tested skin engine and the original default skin, all verifiable headlessly.

**Deliverables**
- **ZIP reader** ported from Bitamp, with the 32 MB / 96 MB / 512-entry caps enforced before allocation.
- **Sheet loading:** ImageIO decoding, sRGB normalisation, clipping and per-sheet fallback.
- **Sprite table:** `scripts/gen-sprites.py`, grown from `spikes/skins-tools/extract_sprites.py`, generates it from Webamp `skinSprites.ts` @ `7734cd3`.
- **Layout tables:** draw rects for Main, EQ, Playlist and the Main shade, cross-checked against Webamp CSS and Strider.
- **Parsers:** ini, viscolor and pledit (from wamp), plus region (macamp's tolerant parser with Webamp semantics).
- **Rendering:** the non-AA region rasteriser; text (FONT_LOOKUP, marquee model, system-font fallback flag, transliteration); the visualiser renderer; EQ slider geometry (51 px) and the eqmain curve; the window composer and hit-testing.
- **Tools:** `skingen` writes `sudamp-dark.wsz` (Bitamp's DefaultSkin, PixelFont and WszWriter, rethemed only, with fixed ZIP timestamps); `sudamp-dev render` writes a PNG plus `.rgba` and `.sha256`; `sudamp-dev skin-load` and `skin-fuzz`.
- **Test data:** AndAmp Dark and Light in `Fixtures/skins/` with CREDITS; committed golden hashes.

**Acceptance criteria**
- `make test` is green, including:
  - the generated sprite table equals `spikes/skins-tools/webamp_sprites.json` (212 rects), except overrides listed in `docs/spikes/sprite-overrides.md`;
  - Webamp's fixtures: 7 region, 4 viscolor and 4 pledit;
  - the marquee `stepOffset`/`loopText` tests; Bitamp's layout, hit-test and slider tests;
  - the cases from Webamp's `snapUtils.test.ts`, run on the pure docking geometry.
- `swift test --filter ZipBomb` rejects a 1 MB archive holding a 1 GiB entry, with peak RSS < 150 MB (`/usr/bin/time -l` on `sudamp-dev skin-load Fixtures/skins/bomb.wsz`, generated at test time).
- `sudamp-dev skin-fuzz Fixtures/skins --mutations 2000` (truncation, bit flips, wrong sizes, nested folders, CP437 names): 0 crashes.
- `make skin-check`: two consecutive `skingen` runs produce the same SHA-256, matching the committed `sudamp-dark.wsz`; an exported skin reloads and renders identically.
- `swift run sudamp-dev render --skin <wsz> --window main|eq|playlist|shade --state Fixtures/states/<n>.json --out /tmp/x.png`: the SHA-256 of the decoded RGBA8 buffer equals the committed golden for sudamp Dark (12 states) and AndAmp Dark (4 states).
- A CJK title in a state fixture sets `marquee.fallback == "system"` in the render metadata; with "always skin font" it uses the transliterated text.
- Tracked, not a gate: `make golden` (about 100 complete museum skins, fetched into Caches) writes `docs/measurements.md#golden`, the share within 0.5% differing pixels in masked Main and EQ areas.

**Dependencies:** M0 (T1). Runs in parallel from M0. S1's outcome decides whether region.txt is wired up in M5.

## M5: Skinned app (L)

**Goal.** The north star in the Winamp shell: the menu opens, Deep House is chosen and music plays, all in sudamp Dark.

**Deliverables**
- **Windows:** `SkinWindow` (borderless, key/main overrides, custom drag); Main + shade, EQ, and the Playlist as a fixed-size station list with `YT`/`SC`/`MC`/`FM` tags.
- **Controls:** transport, seek (VOD only), volume, balance, shuffle/repeat, EQ sliders, ON button, a presets menu over M3's presets and `.eqf` codec, play-state and work indicators, kbps/kHz/stereo fields.
- **Window management:** 15 px docking (child windows only during a drag), frame persistence, MacAmp's screen guard and clamp, uniform 1/2/3x scale (⌘D), always on top.
- **Genre menu** at every anchor: marquee click, options button, right-click, menu bar with ⌘1–⌘9 and ⌘0, status item, Dock. It auto-opens once on first launch, and hovering an item pre-resolves its genre.
- **Visualiser drawing:** spectrum, scope or off, paused when the window is occluded. **Marquee:** the system-font fallback overlay.
- **Library and keys:** favourites (⌘F), ban (⌘⌫), Recently Played/Banned, Copy Link with timestamp, Open Stream URL (Eject, ⌘L), Winamp keys Z, X, C, V, B.
- **Skins:** load by drag-and-drop, `open -a`, Open Skin… or the Skins folder; AndAmp bundled; the exported `.wsz` UTI and `CFBundleDocumentTypes` in Info.plist.
- **region.txt** (only if S1 was GO), behind a kill switch. **Accessibility:** an element for every hotspot. **Snapshots:** `--snapshot <dir>` writes PNG, `.rgba` and `.sha256`.

**Acceptance criteria**
- **(live)** On a fresh profile with the engine installed, `sudamp --profile "$P" --automation Fixtures/automation/northstar.json --json` reports `menuAutoOpened == true`, the Deep House item selected through the menu, `state == "playing"`, and a median `ttfaMs` over 3 runs ≤ 3500.
- `sudamp --snapshot out/ --states Fixtures/states/app/*.json`: every decoded-RGBA SHA-256 equals its golden, covering 12 states across Main, shade, EQ, Playlist and the 1x/2x scales.

## M6: Resilience and engine updates (M)

**Goal.** Nothing a source, network or engine does leaves the user in silence, and engine freshness doesn't depend on app releases.

**Deliverables**
- **EngineStore updates:** the update check right after a `pin` first install; daily and failure-triggered checks; canary-gated switching (with its own `--cache-dir`) and rollback; `_update_spec` and `block` handling; the launch `--version` warm-up; nightly escalation if R1 found the artifact.
- **Failure handling:** DESIGN §6.4's classes and breakers (bot-check/429 6 → 12 → 24 h, engine 15 min → 1 h, transient 15 min → 2 h), with Mixcloud restrictions classed unavailable.
- **Network:** NWPathMonitor drives the SessionMachine `offline` state through `networkLost`/`networkRestored`; YouTube resolutions are dropped when the network path changes.
- **Streams:** background re-resolve 10 min before expiry; mid-stream 403 recovery at the current position; the range-GET probe for progressive YouTube only.
- **Faults:** `SUDAMP_FAULT=youtube:403|youtube:botcheck|youtube:timeout|mixcloud:repeat_play|engine:corrupt|engine:bad-update|net:offline|stream:expire|resolve:delay=<s>`.

**Acceptance criteria**
- `make test`: a crafted m3u8 pointing at `file:///etc/hosts` fails to load; radio hosts resolving to 127.0.0.1, 10.0.0.0/8 or 169.254.0.0/16 are rejected; breaker schedules hold under a fake Clock (bot-check 6 → 12 → 24 h, transient 15 min → 2 h, engine 15 min → 1 h).
- **(live)** `SUDAMP_FAULT=youtube:403 sudamp-dev play --genre deep-house --next-every 15 --seconds 120 --json` (≥ 2 YouTube picks attempted): each failure advances within 1 s; 2 consecutive engine-class failures produce exactly one update check in `metrics.jsonl`; YouTube's breaker opens and playback continues on SoundCloud, Mixcloud or radio.
- **(live)** `SUDAMP_FAULT=youtube:botcheck sudamp-dev play --genre deep-house --source youtube --seconds 30 --json` sets the breaker's `reopenAt` 6 h ahead; a rerun with `SUDAMP_CLOCK_OFFSET=21700` (past the reopen) trips it again and sets it 12 h ahead.
- **(live)** `SUDAMP_FAULT=mixcloud:repeat_play`: the item is skipped within 1 s and classed unavailable, with `nextEligibleAt` 24 h ahead.
- **(live)** `SUDAMP_FAULT=engine:corrupt`: the launch re-hash catches a byte flipped in `_internal/`, the engine is reinstalled or rolled back, and the next pick plays.
- **(live)** `SUDAMP_FAULT=engine:bad-update`: the canary fails, `current.json` is unchanged and the previous engine stays active.
- **(live)** `SUDAMP_FAULT=net:offline` for 30 s: `state == "offline"`, and playback resumes ≤ 5 s after the network is restored.
- **(live)** `SUDAMP_FAULT=stream:expire` on a VOD resumes within 3 s, ± 2 s of the saved position.
- **(live)** An injected 5 s resolve delay on a cold user pick (`SUDAMP_FAULT=resolve:delay=5`) shows `TUNING…`, and audio starts by 6 s with no second yt-dlp process (process count sampled).
- **(live)** `sudamp-dev soak --hours 2 --skip-every 10m` gives 0 crashes, RSS drift < 20 MB and ≥ 97% successful starts.

**Dependencies:** M1. Runs in parallel with M2–M5.
